# IIM Sambalpur Timetable

A simple timetable application for IIM Sambalpur.

## Features
- View timetable information
- Admin interface for managing content
- Responsive web interface

## Run locally
1. Install dependencies:
   ```bash
   pip install flask
   ```
2. Start the app:
   ```bash
   python app.py
   ```
3. Open http://127.0.0.1:5000/
